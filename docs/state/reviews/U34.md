## Advisory
- CSP (public/_headers): script-src 'self' and worker-src 'self' allow /push-sw.js (same origin, covered by the /* header block); push subscription traffic is not under connect-src. No change needed.
- Update gap: registerType is 'prompt' and Turn on reminders uses getRegistration() (the active worker). A phone that still runs a pre-U34 worker can subscribe before it accepts the Reload prompt, and pushes then arrive without a handler. Proposal: in turnOn, if registration.waiting exists, ask for update first or show "Reload to finish updating" before subscribing.
- Notification tag is the type (tag: n.type), so two overdue notifications replace each other on the lock screen. Proposal: tag by notification id or entity in the Worker.
- turnOn awaits registration() before requestPermission(); iOS Safari can be strict about user activation. Proposal: call requestPermission first when Notification.permission is default.
- Sign-out waits for the unsubscribe DELETE and src/data/api/http.ts has no request timeout, so a hung (not failed) request could delay sign-out. Proposal: race removeThisDevicePush with a ~2 s timer.
